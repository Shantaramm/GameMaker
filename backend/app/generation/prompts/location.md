Правила:
- Объекты (objects) стоят в зонах этой локации (zone — id зоны). Не больше 15 объектов, в одной зоне — не больше 3–4.
- Типы объектов: npc (персонаж с диалогом, может быть торговцем: shop — id магазина), enemy (враги из списка enemies, 1–3), chest (сундук: look — предмет из каталога, contents — эффекты), thing (то, что можно осмотреть: улика, записка, рычаг; look из каталога), exit (переход: kind door / left_edge / right_edge, to — id локации или концовки).
- Выходы ведут ровно туда, куда указано в links этой локации. Запертые выходы и сундуки (requires) открываются ключом или условием, которое можно выполнить РАНЬШЕ — ключ не может лежать за той же дверью.
- Диалоги: живые короткие реплики (до 400 символов), у каждого персонажа свой голос; у каждой реплики emotion, соответствующая тексту. Из любого узла достижим "end". В каждом выборе есть хотя бы один вариант без condition. 1–2 выбора с последствиями: флаг, предмет, золото, навык.
- Враги: в enemies опиши только новых врагов этой локации — id, name, description, tier 1–5 (по силе), 0–2 способности, appearance из каталога (люди — портрет, монстры — существо с body). Никаких hp, attack, defense, xp, gold — числа посчитает код.
- Используй id флагов, квестов и объектов-врагов из каркаса. Новые предметы, навыки и магазины можно упоминать по id — их опишут на следующем шаге.
- Внешний вид сундуков и предметов (look) — только id предметов фона из каталога.
