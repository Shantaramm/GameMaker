Правила:
- Объекты (objects) стоят в зонах этой локации (zone — id зоны). Не больше 15 объектов, в одной зоне — не больше 3–4.
- Типы объектов: npc (персонаж с диалогом, может быть торговцем: shop — id магазина), enemy (враги из списка enemies, 1–3), chest (сундук: look — предмет из каталога, contents — эффекты), thing (то, что можно осмотреть: улика, записка, рычаг; look из каталога), exit (переход: kind door / left_edge / right_edge, to — id локации или концовки); если в профиле есть ремесло — gather (место сбора сырья) и station (верстак, котёл, костёр).
- Выходы ведут ровно туда, куда указано в links этой локации. Запертые выходы и сундуки (requires) открываются ключом или условием, которое можно выполнить РАНЬШЕ — ключ не может лежать за той же дверью.
- Темп: реплика — 1–3 предложения (до 300 символов), игрок отвечает хотя бы раз в 2–3 реплики; не больше 3 реплик подряд без выбора. Лучше короче и чаще давать выбор, чем длинный монолог.
- Реплики над головой (barks у npc): 1–3 короткие фразы до 80 символов, которые персонаж бормочет, пока герой проходит мимо, — без окна диалога. Это характер и атмосфера: о чём он думает, чем занят, чего боится. 1–2 фразы с condition отзываются на сделанное игроком (флаг, побеждённый враг, предмет у героя) — так мир замечает перемены.
- Диалоги: реплики до 400 символов, у каждого персонажа свой голос; у каждой реплики emotion, соответствующая тексту. Из любого узла достижим "end". Длина, глубина и число проверок — по профилю выше. Выборы с последствиями: флаг, предмет, золото, навык — и эти флаги меняют будущие реплики.
- Враги: в enemies опиши только новых врагов этой локации — id, name, description, tier 1–5 (по силе), range (дальность атаки: 1 — вплотную, 3–4 — стрелок или маг), 0–2 способности, appearance из каталога (люди — портрет, монстры — существо с body). Бой тактический: смешивай бойцов ближнего боя и стрелков. Никаких hp, attack, defense, xp, gold — числа посчитает код.
- Используй id флагов, квестов и объектов-врагов из каркаса. Новые предметы, навыки и магазины можно упоминать по id — их опишут на следующем шаге.
- Внешний вид сундуков и предметов (look) — только id предметов фона из каталога.
