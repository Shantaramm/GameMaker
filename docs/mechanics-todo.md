## 6. Головоломки (`puzzles`)

**Схема.** Объект карты `type: "puzzle"` — `Puzzle(MapObjectBase)` и ветка в объединении `MapObject`. Поля:

| Поле | Что это |
|---|---|
| `look` | предмет фона из каталога |
| `name` | название |
| `prompt` | что видит игрок |
| `kind` | `"code"` (цифры) или `"sequence"` (порядок рычагов и символов) |
| `options` | для `sequence` — подписи кнопок |
| `answer` | для `code` — цифры строками, для `sequence` — подписи по порядку |
| `clue_ids` | id объектов, где спрятаны подсказки к ответу |
| `on_solve` | эффекты при решении |
| `hint?` | пассивный голос `{skill, difficulty, text}`, который подсказывает часть ответа |
| `bypass?` | обход проверкой `{skill, difficulty}` — взлом или подбор; провал без урона, повтор после роста навыка |

**Валидатор:**
- ответ `sequence` состоит из `options`;
- ответ `code` — из цифр, 3–6 знаков;
- все `clue_ids` существуют;
- эффекты `on_solve` проверяются в контексте `story`;
- замечание `quality`, если механика включена, а головоломок нет.

**Симулятор.** Бот решает головоломку сразу: считается, что игрок прочитал подсказки. Решённое хранится в `HeroState.solved`.

**Рантайм.** `ui.puzzle(obj)`:
- для `code` — кнопки цифр 0–9, «Сброс», «Ввести»;
- для `sequence` — кнопки `options`;
- верный ответ применяет `on_solve` и добавляет id в `state.solved`;
- неверный — «Не подходит»;
- кнопка `bypass` показывает шанс, как у проверки.

Решённую головоломку на карте лучше показывать открытой (как `exitOpen`).

**Контент:**
- демо: кодовый замок на люке в башне маяка; цифры — в дневнике смотрителя и в записи о соли; внутри тайник с вещью;
- «Последняя смена»: сейф директора; код — год открытия музея с фото `opening_photo`.

**e2e.** Ввести код в демо и проверить `state.solved`.

## 7. Мысли героя (`thoughts`, Кабинет мыслей)

**Схема.** `Game.thoughts[]: {id, name, problem, solution, research: 1–5, during: {skill: −1..0}, bonus: {skill: −2..2}, effects: []}`. Поля:
- `problem` — текст пока мысль обдумывается;
- `research` — сколько переходов между локациями её обдумывать;
- `during` — штраф к навыкам на это время;
- `bonus` — постоянный бонус к навыкам после обдумывания;
- `effects` — эффекты после обдумывания.

Мысль получают эффектом `gain_thought: <id>` из разговора: новый эффект в объединении `Effect`, в `STORY_EFFECTS` и в `effects.ts`. Мысли идут на шаг «предметы» (`ItemsContent.thoughts`) с маршрутом `thoughts` в `Pipeline.route`.

**Правила (две копии).**
- В `HeroState` и `GameState`:
  - `thoughts_known` — полученные мысли;
  - `thinking: {id: осталось переходов}` — не больше 2 одновременно;
  - `thoughts_done` — обдуманные мысли.
- Каждый переход в другую локацию уменьшает счётчики.
- Обдуманная мысль применяет `effects`, начисляет опыт и даёт постоянный `bonus`.
- `World.skill` (Python) и `skillValue` (TS) должны учитывать бонусы обдуманных мыслей и штрафы обдумываемых.
- Бот начинает обдумывать мысль сразу, как только получил.

**Интерфейс.** Вкладка «Мысли» в листе героя:
- полученные мысли с кнопкой «Обдумать»;
- обдумываемые с прогрессом;
- обдуманные с текстом `solution` и бонусом.

**Валидатор:**
- ключи навыков в `during` и `bonus`;
- ссылки `gain_thought` на существующие мысли;
- замечание `quality`, если механика включена, а мыслей нет.

**Контент.** «Последняя смена»: 2 мысли — «Учитель без учеников» из скамейки у окна и «Цена крыши» из разговора с директором.

## 8. Время суток (`daynight`)

**Схема:**
- `Game.clock: {start: "day" | "dusk" | "night", steps: 2–6} | None` — фаза меняется каждые `steps` переходов: день → сумерки → ночь → день;
- новое условие `{time: "day" | "dusk" | "night"}` — в `Condition`, `conditions.ts` и `check()` в `simulator.py`.

**Правила.**
- Счётчик переходов хранится в `HeroState` и `GameState` (`ticks`).
- Фаза = `phases[(start + ticks // steps) % 3]`.
- Условие `time` работает везде: присутствие объектов, реплики над головой, события, выходы.

**Валидатор:**
- если условие `time` где-то используется, `clock` обязателен;
- замечание `quality`, если механика включена, а `clock` или условий `time` нет.

**Рантайм:**
- уличный фон рисуется с текущей фазой вместо `background.time` (`BackgroundView` получает `{...spec, time: phase}`);
- в HUD — значок фазы и кнопка «Ждать» (следующая фаза без перехода);
- бот может «ждать», если в локации нечего делать.

**Контент.** «Почтальон»: ночью у заставы меньше часовых (условие `time` у одного часового); днём перевал виден, ночью волки злее (бонус по флагу). Включить `daynight` в профиле этой игры.
